# Welcome Splash

## Design Context

```
App: ForgeAI — AI Home Gym Coach
Style: Athletic Clean Sport — light-first, sport energy
Background: warm ivory #F9F7F4
Cards: white #FFFFFF, border #E2E0DC, radius 16px, subtle shadow
Primary accent: Sport Orange #F05A1F
Secondary accents: Blue #2070CC (AI), Green #2BA86A (success), Amber #F5A623 (energy), Purple #7C5CC4 (recovery)
Headings: DM Sans ExtraBold/Bold, dark #1A1A1A
Body: Manrope Regular/SemiBold, #5C5C5C
Stats/Timers: JetBrains Mono Bold
Icons: Phosphor Bold, 24px, #8C8C8C inactive → #F05A1F active
Spacing: 8px grid. Screen padding 16px.
Platform: Mobile app (iPhone 15 Pro frame, 393×852)
NO glassmorphism. NO neon. NO dark-mode-first. Clean, solid, sporty.
```

## Prompt

A clean, confident mobile welcome screen for a fitness coaching app called "ForgeAI." Athletic Clean Sport aesthetic — warm, light-first, and energizing.

**DESIGN SYSTEM (REQUIRED):**

- Platform: Mobile (iPhone 15 Pro, 393×852), portrait orientation
- Palette: Warm Ivory (#F9F7F4) page background, Sport Orange (#F05A1F) for primary CTA, Dark (#1A1A1A) for heading text, Muted Gray (#5C5C5C) body text
- Styles: Generously rounded corners (16px radius), whisper-soft diffused shadows, solid flat cards — NO glassmorphism, NO neon glow

**PAGE STRUCTURE:**

1. **Status Bar:** Standard iOS status bar at top, dark text on warm ivory background

2. **Central Content (vertically + horizontally centered):**
   - Abstract geometric "F" logomark — bold, angular, sport-inspired mark using Sport Orange (#F05A1F). Minimal, no text inside the logo. Roughly 80×80px size
   - Below logo: App name "ForgeAI" in DM Sans ExtraBold, 28px, dark #1A1A1A
   - Below app name: Tagline "Your AI Coach Lives Here" in Manrope Regular, 16px, muted gray #5C5C5C. Subtle, understated, confident

3. **Bottom Section (pinned to bottom safe area with 16px padding):**
   - Full-width primary call-to-action button: "Get Started" in white text, DM Sans Bold, 16px
   - Button background: solid Sport Orange (#F05A1F), pill-shaped (rounded-full), height 56px
   - Whisper-soft shadow beneath the button for slight elevation
   - Below button: "Already have an account? Sign In" as a text link in muted gray #5C5C5C, Manrope SemiBold, 14px. "Sign In" portion uses Sport Orange color

4. **Overall Feel:** Generous whitespace, breathing room, minimal — only logo, tagline, and CTA visible. Clean, confident first impression. No clutter, no illustrations, no background patterns. The warm ivory background provides a sporty yet inviting canvas.

## Notes

- This is the first screen users see — it must convey premium quality and confidence instantly.
- The geometric "F" mark should feel modern and athletic, not corporate or boring.
- Ensure enough vertical spacing between logo, tagline, and CTA to feel balanced and airy.
- No onboarding progress dots on this screen — it's a standalone welcome gate.
